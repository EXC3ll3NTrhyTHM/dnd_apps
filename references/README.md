# Character & Scene Reference Images

Drop reference images here for the quest image generator.

## Folder Structure

### `characters/`
One image per character. Name the file after the character (lowercase, no spaces).

Examples:
- `aly.png` - Aly (main PC)
- `ithrae.png` - Ithrae (air genasi)
- `bonesy.png` - Bonesy (skeleton)
- `wren.png` - Wren (quest NPC from Rooftop Kingdom)
- `nibby.png` - Nibby (goblin)

**Best reference images:** Clear front-facing or 3/4 view, good lighting, minimal background clutter. The generator uses these to maintain character consistency across quest scenes.

### `locations/`
Reference images for recurring locations.

Examples:
- `okhan_market.png`
- `rooftops.png`
- `tavern.png`

### `style/`
Art style reference images. Drop 1-3 images that represent the target painterly fantasy style. The generator uses these as style anchors.
